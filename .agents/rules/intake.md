# Rule: Intake (Planning Gate)

> Scope: `plans/intake/**`, `plans/plan.md`, `ATOMIC_TICKET.md`

## Requirements
1. Conduct requirements intake; validate scope (IN/OUT), dependencies, acceptance criteria, stop conditions.
2. Write intake reports exclusively to `plans/intake/<topic>.md`.
3. Never write directly to `ATOMIC_TICKET.md` or `plans/plan.md` (reserved for lead).
4. Hand off validated intake packages to lead for ticket decomposition.
5. Tier 3 work requires ADR review before intake approval.
