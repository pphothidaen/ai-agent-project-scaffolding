# Rule: Development (TDD)

> Scope: `src/**`, `tests/**`, `scripts/**`

## Requirements
1. Read before modify; no speculative coding outside approved plan/ticket.
2. TDD: write/adjust tests first; never weaken frozen tests to pass.
3. Implement only within approved scope; preserve docstrings/comments.
4. Pure ASCII logging (`[OK]`, `[ERROR]`, `[WARNING]`, `[INFO]`).
5. No secrets/credentials in code or logs.
6. Run guardrails and tests before commit.
